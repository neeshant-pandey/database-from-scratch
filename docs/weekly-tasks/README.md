# Weekly Tasks

This directory tracks our weekly learning tasks and progress.

## Task Format

Each week's task should be documented in a separate file: `week-NN.md`

### Template

```markdown
# Week N: [Topic Name]

**Date**: YYYY-MM-DD
**Team Members**: [List members]

## Goals
- [ ] Goal 1
- [ ] Goal 2
- [ ] Goal 3

## Learning Objectives
What we want to understand by the end of this week.

## Implementation Tasks
Specific coding tasks to complete.

## Research & Reading
Resources to study this week.

## Challenges Faced
Document any difficulties and how we solved them.

## Key Learnings
Important insights gained this week.

## Next Week Preview
What we'll tackle next.
```
